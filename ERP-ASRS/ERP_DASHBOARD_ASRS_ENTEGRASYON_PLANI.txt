ERP Dashboard ve AS/RS Komut Entegrasyonu - Uygulama Plani
==========================================================

Hedef
-----
Dashboard'dan konum bazli RETRIEVE, RFID tetiklemeli otomatik STORE,
Arduino'ya guvenli komut akisinin kurulmasi.


Net Kurallar (Bu projeye ozel)
------------------------------
1. Sistem location-based calisacak, urun-RFID eslesmesi olmayacak.
2. Her RFID karti sabit bir raf hucresine (row,col) eslenmis olacak.
3. RFID okutuldugunda sistem bos hucre aramayacak; kartin map edildigi hucreyi kullanacak.
4. RETRIEVE sadece dashboard hucre tiklamasiyla row+column uzerinden tetiklenecek.
5. STORE sadece RFID okutma olayi ile otomatik tetiklenecek.
6. Arduino'ya giden komutlar:
   - STORE:<col>:<row>
   - RETRIEVE:<col>:<row>
   - HOME
   - STATUS


1) Veri Modeli (DB)
-------------------
1. RackCells tablosu:
   - Id
   - Row
   - Col
   - IsOccupied
   - LastCommandId
   - UpdatedAt

2. AsrsCommands tablosu:
   - Id
   - Type (STORE/RETRIEVE/HOME/STATUS)
   - Row
   - Col
   - Source (Dashboard/RFID)
   - Status (Queued/Sent/Busy/Done/Failed)
   - Error
   - CreatedAt
   - CompletedAt

3. RfidEvents tablosu:
   - Id
   - CardUid
   - TriggeredAt
   - ResultCommandId
   - Result

4. Kisitlar:
   - RackCells(Row, Col) unique olmalidir.

5. RfidRackMap tablosu (yeni):
   - Id
   - CardUid (UNIQUE)
   - Row
   - Col
   - IsActive
   - UpdatedAt

6. Ek kural:
   - Her aktif CardUid yalnizca tek bir row,col konumuna isaret eder.


2) API Katmani (ASRS.API)
-------------------------
1. POST /api/asrs/retrieve
   - Input: row, col
   - Islem: RETRIEVE komutu olusturur.

2. POST /api/asrs/rfid-scan
   - Input: cardUid
   - Islem:
     a) cardUid -> RfidRackMap icinde row,col bulunur
     b) Bu row,col icin STORE komutu olusturulur
     c) Kart map edilmemisse hata donulur (RFID_NOT_MAPPED)

3. GET /api/asrs/commands/next
   - Raspberry Pi kuyruktan bir sonraki komutu buradan alir.

4. POST /api/asrs/commands/{id}/ack
   - Pi/Arduino durum geri bildirimi (BUSY/OK/ERR).

5. GET /api/asrs/rack-state
   - Dashboard hucre doluluk durumu.

6. GET /api/asrs/system-status
   - Son Arduino durumu, online/offline, son hata.


3) Komut Orkestrasyonu
----------------------
1. Ayni anda tek aktif komut kurali (lock/mutex).
2. Durum akisi:
   - Queued -> Sent -> Busy -> Done/Failed
3. Timeout + retry politikasi (ornek: 1 retry, sonra Failed).
4. Done olunca RackCells doluluk guncellenir.
5. Failed olunca hucre durumu degismez, hata loglanir.


4) Raspberry Pi Bridge Servisi
------------------------------
1. API'den next command cek.
2. Arduino'ya serial yaz:
   - STORE:x:y\n
   - RETRIEVE:x:y\n
3. Arduino cevaplarini oku:
   - BUSY
   - OK:...
   - ERR:...
   - READY
4. Tum durum degisimlerini API'ye ack ile yaz.
5. Baglanti koparsa auto-reconnect + health check.


5) Dashboard (ASRS.Web)
-----------------------
1. Sol panel:
   - 3D gorsellestirme (ilk asamada placeholder + canli komut baglantisi).

2. Sag panel:
   - Row/Col hucre grid'i
   - Dolu/Bos renkleri
   - Hucre tiklama ile RETRIEVE tetigi

3. RFID otomatik STORE bildirimi:
   - RFID olayi geldiginde otomatik STORE baslatildigini goster.

4. Canli izleme:
   - Komut gecmisi
   - Son durum karti (Queued/Busy/Done/Failed)


6) Indeks ve Protokol Standartlari
----------------------------------
1. UI 1-based gosterebilir.
2. API icinde normalize edilmeli.
3. Arduino 0-based zorunlu:
   - col: 0..3
   - row: 0..2
4. Tek mapper fonksiyonu kullanilmali:
   - uiToArduino(row,col)
   - arduinoToUi(row,col)


7) Guvenlik ve Yetki
--------------------
1. Komut endpoint'lerine rol bazli yetki:
   - Depo, Yonetici
2. Pi-API arasinda cihaz kimligi:
   - ApiKey veya JWT
3. Audit log:
   - Kim, ne zaman, hangi hucreye komut verdi


8) Test ve Devreye Alma
-----------------------
1. Unit test:
   - RFID->raf map cozumleme
   - State machine
   - Mapper

2. Integration test:
   - Dashboard -> API -> Queue

3. Hardware-in-loop test:
   - Pi mock + gercek Arduino ile STORE/RETRIEVE

4. Failure test:
   - Serial timeout
   - ERR donusu
   - Reconnect senaryolari


Onerilen Sprint Sirasi
----------------------
Sprint 1:
- DB + API command lifecycle + rack state

Sprint 2:
- Dashboard grid + RETRIEVE butonu + canli durum

Sprint 3:
- RFID endpoint + RFID->raf map yonetimi

Sprint 4:
- Pi bridge + gercek Arduino entegrasyonu + stabilizasyon


Ozet
----
- STORE: RFID tetikler, sistem kartin map edildigi hucreyi bulur, Arduino'ya STORE col/row yollar.
- RETRIEVE: Dashboard hucre secimi ile row/col alinir, Arduino'ya RETRIEVE gonderilir.
- Is kurali ve karar katmani Web/API'dedir.
- Fiziksel hareket katmani Arduino'dadir.
- Raspberry Pi iki dunya arasinda kopru gorevi gorur.
